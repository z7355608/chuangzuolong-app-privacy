前言与特别提示

创作龙app面向商家与创作者，提供商品图、穿搭图、海报与视频的 AI 创作，以及 Agent 任务、模板、工具、作品资产、会员、创点和订单服务。我们按照合法、正当、必要和诚信原则处理个人信息。本政策说明我们处理哪些信息、为什么处理、何时调用设备权限、如何与服务方合作，以及你怎样行使权利。

请重点阅读创作素材与 AI 处理、第三方 SDK 和广告、设备权限、敏感个人信息、账号注销等部分。某项功能未在你使用的版本提供时，与该功能对应的权限和 SDK 不应因此启动。关闭可选权限或拒绝非必要的信息处理，不应影响其他独立功能。

本政策适用于创作龙app的 iOS 和安卓客户端及其在应用内提供的服务。网站和微信小程序分别适用其自身已公示的隐私政策；使用同一账户跨端登录时，账户、任务、资产、会员及创点权益可能同步。

一、定义与处理原则

个人信息是以电子或其他方式记录、与已识别或可识别自然人有关的信息。敏感个人信息包括生物识别、特定身份、医疗健康、金融账户、行踪轨迹，以及不满十四周岁未成年人的个人信息等。你上传的照片、视频、语音、商品资料和提示词可能含有你或他人的个人信息；我们按照其实际内容和使用场景保护。

“创作素材”指你主动输入、选择、拍摄或上传的文字、图片、视频、音频及其他文件；“作品”指任务生成结果及保存到资产库的内容；“第三方 SDK”指为实现特定能力而集成到客户端的软件组件。服务端调用的存储、短信或生成接口不等于这些机构的 SDK 均安装在你的设备上。

我们将信息用于你选择的服务、履行合同、遵守法定义务、维护账户和交易安全，或在需要时依据你的同意处理。处理目的、方式和信息种类发生实质变化时，我们将重新告知，并依法取得相应同意。请勿上传与创作无关的证件、银行卡、病历等资料；使用含他人肖像、声音或联系方式的素材前，请取得必要授权。

二、我们如何收集和使用个人信息

2.1 账户注册、登录与资料

你注册或登录时，我们处理手机号、短信验证码、登录凭证、登录时间及必要的安全日志。你可以设置或授权昵称、头像等资料；若选择微信等第三方登录，我们仅取得完成该次授权与账户绑定所需的身份标识及获你授权的资料。拒绝提供登录所需信息，会使账户同步、云端任务和交易功能无法使用，但不影响版本中无需登录即可使用的内容。

若某项服务依法要求实名认证，我们将在该功能入口说明依据、收集字段和验证服务方，再处理姓名、身份信息等；不会把实名认证作为全部功能的默认前提。

2.2 Agent、模板、工具与 AI 创作

你发起商品图、服饰穿搭、海报或视频任务时，我们处理你提交的需求、提示词、商品信息、模板与工具选择、生成参数，以及你主动选取的图片、视频或音频。为完成任务，所选内容会经过必要的内容安全检查、任务规划、模型生成、结果存储和交付。我们记录任务编号、状态、处理时间、失败原因及与你账户关联的结果，以便继续任务、查看进度、反馈和售后。

你上传的人像、声音或其他可识别内容可能构成敏感个人信息或涉及第三人权利；如处理依法需要单独同意，我们会在使用该功能前单独告知并取得同意。我们不会因你仅打开应用就读取设备中的全部照片、视频或文件，也不会将你的私有素材用于与所选服务无关的广告定向。

2.3 作品下载、资产与历史记录

你查看、保存、下载、删除或再次使用作品时，我们处理相应任务和资产编号、操作记录、必要的文件元数据与下载结果。云端资产与本机文件分开管理；你主动保存到本机时，才调用系统提供的保存能力。删除云端作品后，依法须保留的订单、安全与争议记录仍按本政策保存。

2.4 会员、创点、付款、订单和发票

你购买会员或创点、使用付费创作服务时，我们处理商品、价格、订单编号、支付渠道及状态、交易凭证、权益、余额与使用流水、退款与售后记录。我们向支付渠道传递核验付款所需的订单数据，并接收支付结果；不取得你的完整银行卡号或支付密码。iOS 内的数字功能购买按 Apple 应用内购买处理，安卓按该版本实际提供的支付渠道处理。申请发票时，另处理你主动提供的抬头、税号、邮箱等开票资料。

2.5 客服、投诉与活动

你求助、投诉或申诉时，我们处理你提交的联系方式、问题描述、截图、任务或订单编号和处理往来记录，用于定位问题、答复及保存必要证据。若应用举办活动并发放实物、现金或其他奖励，我们将在活动规则中另行说明所需的收件人、地址或收款账户等信息；不参加活动无需提供。

2.6 运行维护、统计与安全

为维持服务、修复故障、防范盗号、恶意上传和重复扣费，我们处理 IP 地址、请求时间、APP 版本、设备型号、操作系统版本、网络与接口状态、崩溃和操作日志、请求或幂等编号。统计分析优先使用汇总或经过必要处理的数据；若某项统计或广告组件需要取得超出运行所必需的信息，我们会单独说明并依法征得同意。

2.7 依法无需另行取得同意的情形

在法律允许范围内，为订立和履行与你的合同、履行法定义务、应对公共卫生事件或紧急保护生命财产安全等，可以依据相应法定事由处理必要信息。即使适用这些情形，我们仍限制处理目的、信息种类和保存期限。

四、Cookie、设备本地存储及同类技术

应用可能通过本地存储保留会话、必要设置和临时缓存；内嵌网页可能使用 Cookie 或同类技术维持登录、安全校验和页面状态。你可以退出登录、清除应用数据，或按浏览器和系统提供的方式管理 Cookie。清除后可能需要重新登录，尚未同步的本地内容也可能无法恢复。超出必要运行范围的统计、广告或跨应用追踪将依照相应规则另行告知和处理。

六、第三方 SDK 与广告服务

原生 SDK 与服务端合作方分别管理。每个实际接入客户端的 SDK，应在下方目录写明名称、运营者、用途、处理的信息、权限、启动时机与隐私规则；**未安装到某个版本的 SDK 不会因出现在规划目录中而运行。**应用内的正式清单应与该版本安装包一致，不能仅凭本政策文字推断某 SDK 已经接入。

6.1 登录、付款、统计与消息

微信开放平台组件只在用户选择微信授权、分享或对应支付路径时调用；支付组件只在进入相应收银台时调用；统计、崩溃分析与推送组件若接入，则分别用于衡量功能使用、定位故障和发送你选择的消息。它们可能处理 APP 版本、设备型号、系统版本、网络状态、错误日志或推送标识；是否处理 Android ID、OAID、IDFA、精确位置等，应以该版本实际 SDK 清单和单独告知为准。我们不会把所有可能字段笼统写成每次启动都会收集。

6.2 广告展示、监测与个性化

若版本提供广告位或广告换取权益的功能，广告合作方可能在展示、点击、归因与反作弊时处理设备型号、系统版本、APP 版本、IP 地址、网络状态、广告标识符、交互日志等必要信息。涉及 IDFA、精确位置、安装列表或个性化广告的，还应在实际使用前按系统规则和法律要求另行告知、请求授权或取得同意。广告服务不能在用户尚未作出相应选择前，超范围启动收集。

如提供个性化广告，我们将在应用内提供关闭或调整入口；关闭后可能仍会看到非个性化广告，但不再使用对应的个性化处理。拒绝广告追踪或定位授权，不应影响创作、作品管理和已购买权益。具体广告 SDK 及其处理细节见本政策附录；未开通的广告服务不应处理你的个人信息。

6.3 SDK 管理措施

我们评估接入必要性、检查 SDK 隐私说明和权限、限制初始化时机，并通过合同、版本管理、日志和检测工具监督其处理活动。SDK 版本或处理范围有实质变化时，更新目录和相应告知。服务方的独立隐私规则由其另行提供；如与我们公示的实际处理不符，请通过本政策联系方式反馈。

七、保存地点、期限与跨境提供

面向中国大陆用户收集的个人信息原则上存放在中国境内。账户资料通常保存至注销或处理目的完成；任务、作品和资产在你保留账户及使用该功能期间保存。临时访问凭证届满失效，临时处理文件在完成用途后清理。订单、创点流水、发票、支付对账、投诉和安全记录，按照履约、税务、财务、网络安全及争议处理的适用期限保存；期满后删除或匿名化。法律要求继续保存或技术上暂时无法删除时，仅限保存和必要的安全保护。

如某项服务需要向境外提供个人信息，我们会先履行适用的评估、认证或合同程序，告知境外接收方和处理情况，并在法律要求时取得你的单独同意。未完成相应程序前，不因本政策的概括说明而默认进行跨境提供。

八、安全保护与事件处理

我们采取传输加密、访问控制、身份验证、权限分级、日志脱敏、受控文件链接、备份和操作审计等措施，降低信息泄露、毁损或丢失风险。请妥善保管账号、密码和验证码，不要向他人提供。互联网服务无法保证绝对安全；发现异常登录或资料泄露时，请及时联系我们。

发生可能影响你权益的个人信息安全事件时，我们将启动处置流程，采取止损、排查和补救措施，依法向监管部门报告，并通过应用通知、短信、邮件或公告等合理方式告知事件情况、影响、处置和防范建议。

九、你的个人信息权利

**查阅、复制、更正与补充：**你可以在账户、任务、资产、会员、创点和订单页面查看相应记录，并在开放的资料入口修改资料；其他请求可通过联系邮箱提出。为防止冒用，我们可能核验身份。

**删除：**处理目的已实现、不再必要、保存期限届满、你依法撤回同意，或我们违反法律及约定处理信息时，你可申请删除。依法须保留的记录将在受限状态下继续保存；备份数据会按备份周期清理。

**撤回授权：**你可在系统设置关闭相机、照片、麦克风、通知、位置等权限，在应用提供的设置中管理个性化广告或其他基于同意的处理。撤回不影响此前基于有效授权完成的处理；对应功能可能无法继续使用。

**获取副本、转移与解释：**你可以申请个人信息副本、了解处理规则；符合国家网信部门规定条件的，可以申请转移个人信息。我们会说明可提供的范围、方式及安全验证要求。

**注销账户：**你可在 APP 账户设置发起注销，或发送邮件申请。注销前，我们会提示生成中的任务、未结算付款、处理中发票、退款、会员权益及剩余创点的处理方式，并完成必要的身份和安全验证。注销完成后撤销登录会话，账户与原有资产无法继续访问；依法须保存的交易、安全记录限制处理。

**投诉与响应：**你认为信息处理损害权益时，可通过 APP 内帮助、反馈与投诉入口或本政策邮箱联系我们。我们在核验身份后依法定期限答复；不能满足请求时说明理由。你也可以向有管辖权的主管机关投诉或依法寻求救济。

十、未成年人保护
